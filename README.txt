反映内容
1. 結果画面のSTは本番データだけを使用。展示STからの代用を削除。
   本番未取得時は、船を仮の位置に配置せず「本番ST未取得」と表示。
2. 黄色線の右端＝0.00を水面幅78％の位置へ移動。
   0.99側の基準は7.5％。通常ST側の幅は54→70.5ポイント（約31％拡大）。
3. 詳細タブ内の小さい文字は原則12px以上、主な数値・選手名は14px。
   読みやすい文字サイズを保つため、細かい表はスマホで横スクロール対応。
4. 直近20走の白い１号艇チップを濃い枠線＋淡いグレーへ。
   日付を押すと、その日・場・Rの公式結果が別タブで開く。
5. コース別成績を期間別に表示。今回の集計対象は2026年9月12日の581選手。
   2025年9月12日～2026年9月11日の365日分、124,219走を使用。
   1ヶ月・3ヶ月・6ヶ月・1年は暦月でさかのぼり、当日を含めず集計。

集計の定義
・1着率、2連対率、3連対率、決まり手割合：該当の実進入コースの出走数が分母。
・枠別1着率：実進入ではなく枠番を基準にした1着率。
・平均STとST順位：F・Lなどを除外。有効なSTが同じ艇は同順位。
・平均展示順位：当該レースの展示タイムを比較。同値は同順位。
・逃し率：対象選手がそのコースから出走したレースで1コースが逃げた割合。
・差され率等：1コース出走時に相手が該当の決まり手で勝った割合。
・対象なし：その期間の該当出走なし。記録なし：有効な記録なし。
・対象外：画面上の指標を適用しないコース。
・画面上部の「公式コース別成績」は公式選手ページの集計期間を維持。
  その下の期間別表は公式競走成績ファイルからの独自集計。

今後の更新
追加のworkflowは日本時間08:20に日次実行（GitHub側の遅延はあり得ます）。
Actions → Update course statistics → Run workflow でも手動実行できます。
事前に既存の収集処理で today.json を当日分へ更新してください。
初回は1年分を収集。以後はキャッシュ済みの公式成績ファイルを再利用します。
未取得日がある場合は、公開済みの集計ファイルを上書きしない設定です。
当日の選手情報が後から更新された場合は、このworkflowも再実行してください。
